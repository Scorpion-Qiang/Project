实现服务器API，要先明确前后端交互的方式，前后端交互使用JSON格式
一、请求题目的列表
   请求： GET/problem
   响应：
   [
      {
         id: "1",
         title: "两数相加",
         level: "简单"
      }

      {
         id: "2",
         title: "迷宫问题",
         level: "中等"
      }
      .
      .
   ]
二、请求某个题目的详情信息
   请求：GET/problem?id=1
   响应：
   {
       id: "1",
       title: "两数相加",
       level: "简单",
       description: "题目描述..."
       templatecode: "初始代码模板.."

   }
三、提交代码
   请求：POST/submitcode
        body:
             {
                 id: "1",              (一定要传题目id，因为服务器通过id找到这个题目，得到它的测试用例，拼接用户提交的代码，编译运行)
                 code: "..."
             }
   响应：
   {
       error: "0/1/2",                 (0表示编译运行成功，1表示编译报错，2表示运行出错)
       reason: "编译运行出错的原因",
       stdout: "编译运行的结果"           (哪个测试用例通过了，哪个测试用例卡住了)
   }
